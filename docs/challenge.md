# Builders - Mech Royale

為一台機甲撰寫 AI，在 OSU 校園進行 16 人 3D 大逃殺。最後存活的機甲獲勝。

## 遊戲

16 台機甲空降到 OSU Oval，周圍有建築、屋頂和樹木可以掩護作戰，安全區在約七分鐘內逐漸縮小。每台機甲開局都有一把手臂槍；迫擊砲、蓄力雷射和閃電要在比賽中拾取，擊殺和補給箱掉落的能量方塊（power cube）可以購買升級。計分看名次，不看擊殺數：帶著五殺最先陣亡，分數比零擊殺撐到最後還差。

現在就能在瀏覽器遊玩：<https://play.joinbuilders.org>。計分比賽只有 bot 參加：每秒十次，你的程式會收到機甲看到和聽到的資訊，並回覆要往哪移動、往哪瞄準、是否開火。

## 三步開始

1. 下載下方的 `mechfight-kit.tar.gz`，把其中的 Python 或 TypeScript 資料夾複製到一個公開 GitHub repo 的根目錄（Dockerfile 放在最上層）。
2. 建置映像檔，並依照 kit 的 README 中的指令，用 `check/check.py` 測試。
3. 推送（提交的 commit 最多 20 MB），然後在此提交 repo URL。

任何語言、函式庫或 AI 皆可使用。建置在 linux/amd64 上進行，有網路，最多 10 分鐘；請固定版本，因為決賽隊伍會重新建置。

## Bot 介面與限制

- 透過 stdin 與 stdout 以 JSON lines 使用 `mechfight/1` 協定（見 `protocol.md`）。
- 每個觀測（observation）有 50 ms 可以回覆。遲到的回覆會被跳過，你的機甲會維持上一次的移動與瞄準但不開火 1 秒，之後停在原地。回覆時間在不同次執行與不同機器間會差幾 ms，所以回覆時間接近上限的 bot 重跑時分數可能不同。
- 容器有 1 顆 CPU、512 MB 記憶體，以及唯讀地圖於 `/arena`。
- 執行時沒有網路、沒有 root（bot 以 uid 65534 執行，所以套件要裝在系統層級），除了 `/tmp`（64 MB）以外不能寫入磁碟。

## 文件與起始檔案

- `protocol.md`：完整規則書，包含競技場、武器、觀測、動作與 `mechfight/1` 協定（也在 `mechfight-kit.tar.gz` 裡）。
- `mechfight-kit.tar.gz`：Python 與 TypeScript 起始 bot、wrapper、Dockerfile、`protocol.md`、JSON Schema、`check/check.py` 與地圖。

## 計分

| 項目 | 內容 |
| --- | --- |
| 指標 | 名次分數，越高越好 |
| 要超越的基準 | 1.15（Starter：kit 的 Python 範例 bot） |
| 公式 | 一次執行中所有比賽的 (16 - 名次) 平均 |
| 同分 | 同分時較早的提交排前面 |
| 計分器版本 | builders-3 |

每場比賽得 16 - 名次 分：獲勝 15 分，最先陣亡 0 分。同一 tick 陣亡者共享名次。你的分數是所有比賽的平均。

## 規則

- 練習賽打 48 場，對手是 15 個 house bot（4 easy、4 medium、4 hard、3 expert），它們組成一個小隊：共享視野、彼此不互打，並從最弱的開始獵殺你（前期一台，隨著你削減它們的數量越來越多，後期全部）。
- 練習賽的 seed 是私密的，整個活動期間固定。你的 bot 永遠看不到 seed，每場比賽的位置與出生點都會變。
- 每個參賽作品都必須能建置並在執行限制下通過 `check/check.py`。建置或檢查失敗會被拒絕並附上原因，不影響你的最佳分數。
- 崩潰或停止回覆的 bot 會留在比賽中當活靶並照常計分，不會被拒絕。
- 每隊每小時可提交 4 次，一次提交通常幾分鐘內計分完成。排行榜列出各隊最佳練習分數，並附上 starter bot。
- 在結果公布前，repo 必須保持公開並保留每個提交過的 commit；決賽時無法取得或建置的作品得零分。

## 決賽

截止時，你選定的提交（預設為最佳，除非另選）會連同其練習分數鎖定。前 32 隊進入資格賽：每隊對其他晉級者在新 seed 上打 16 場（16 台機甲混戰）。資格賽 (16 - 名次) 平均前 16 名晉級，公布時不顯示分數。16 支決賽隊伍一起在新 seed 上打 64 場系列賽（16 台機甲混戰）；最後 4 場在會場現場進行，計分相同。決賽排名只看系列賽平均，所有同分以較早提交者優先。主辦方可在決賽開始前調整場數，開始後不會再改。

- 不足 32 隊時，所有隊伍都打資格賽；16 隊以下則全部直接打系列賽。
- 空位由 expert house bot 補上。
- 若資格賽作品無法取得或建置，該隊輪空，由練習榜下一隊遞補。
- 非決賽隊伍排在決賽隊伍之後（被淘汰的資格賽隊伍依資格賽分數排序，其餘依練習榜順序，以負分顯示）。
- 最後一場比賽結束前排名都不公開。

截止時間：週日上午 11:00 EST。
